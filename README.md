Desafio Bootcamp Dio-Heineken


🧱 Passo 1: Defina a Intenção
Resposta

Quero que a IA gere um plano de estudos para profissionais de tecnologia, com o objetivo de desenvolver conhecimentos em Inteligência Artificial, Ciência de Dados, Engenharia de Dados e MLOps.

🧱 Passo 2: Adicione Contexto e Restrições
Resposta

Considere o seguinte contexto: profissional com experiência em desenvolvimento de software que deseja migrar para uma carreira focada em Inteligência Artificial e Dados.

O conteúdo deve ter formato de cronograma semanal contendo:

Temas de estudo
Objetivos de aprendizagem
Sugestões de projetos práticos
Tempo estimado de dedicação

Evite:

Linguagem excessivamente técnica
Conceitos avançados sem explicação prévia
Conteúdos sem aplicação prática


🧱 Passo 3: Prompt Final

Quero que a IA gere um plano de estudos para profissionais de tecnologia, com o objetivo de desenvolver conhecimentos em Inteligência Artificial, Ciência de Dados, Engenharia de Dados e MLOps.

O conteúdo deve ter formato de cronograma semanal contendo temas de estudo, objetivos de aprendizagem, sugestões de projetos práticos e tempo estimado de dedicação.
